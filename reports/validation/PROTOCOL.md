# 断句、恢复与服务验证协议

## 输入约束

只有阅读接口 `/api/process` 的 punctuate 使用输入依赖的 GBNF。输入按 NFC 规范化后逐字符固定，已有标点、数字、小数点和空白都不得删改；每个间隙只允许增加至多两个白名单中文标点。原文字符经过转义，不当作语法规则执行。翻译和通用聊天使用普通生成。

独立状态机另验完整候选，达到 token 预算的前缀不算完成；不通过修补候选来伪造模型得分。结构契约不保证语义校点正确或引号平衡。

## 质量对照

开发断句题用于方案选择，固定 tokenizer/template、greedy、seed24、512 token 上限和关闭 prompt cache。比较基座/微调 Q8 的自由与约束输出，再比较同一微调 checkpoint 的 Q8/Q4；补充两示例基座，防止弱提示基线放大训练收益。

开发选择后冻结增量保留题 ID（bench/ood 各 20），仅对微调 Q8 比较自由与约束。每组的生成前门槛为严格 F1 下降不超过 0.01、完整正文一致率至少 0.98。原始输出、题目 ID、输入资格、参考、模型及协议指纹保存在相邻 JSON/JSONL。

严格边界 F1 在正文变化时归零，另报标点类型 F1、正文保真和字符错误。参考未获专家逐题校点，分数不代表语义准确率；样本区间不覆盖训练种子或典籍分布变异。已经评分的题目后续不得再称未见测试。

## 资源与取消

本机原生服务仅监听 localhost，实际生成单槽位，使用独立访问令牌并禁止静默 CPU 回退。网关取消、连接断开或截止时中断原生请求，再确认 `/slots` 空闲才归还容量；失败则隔离引擎、拒绝后续生成并要求重启。

分别检查 SSE 断开、非流式 JSON 断开、显式取消、排队取消和整篇截止。检查依据是服务槽位状态，不宣称 GPU 内核级抢占。

## 持久化与页面

SQLite 保存精确原文、段结果和 revision。文档身份绑定输入、任务、模型/模板/约束/后端与推理代码；完成段和人工修订可以恢复，未完成段重新生成。缓存命中本次 usage 为零，原生成 usage 单独保留；部分导出保留未处理原文。

停止并重启网关和原生后端后，核对修订、完成段数、恢复仅补剩余段、重复请求没有新增 token，并以旧 revision 保存确认 409。同文档生成期间阻止另一路生成或编辑。

浏览器检查使用项目隔离的无头 Edge，操作实际 DOM 和真实 GPU 后端；不读取日常浏览器配置。程序测试、API 检查和页面检查分别记录。

## 发布后的复核

公开的是当前源码和选定证据，完整本地资产不分发。历史测量文件的源代码 hash 保持原值；文档和输出路径整理后，当前代码 hash 不冒充测量时的 hash。本次打包另做程序、脚本语法、文档链接、秘密与忽略清单检查，不重新宣称跑过完整训练和所有真实 GPU 对照。
